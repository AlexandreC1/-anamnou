# Phase 0 API

The API binds to 127.0.0.1:4000 by default. Browser traffic uses /api through the
web server proxy. GET /openapi.json serves the generated OpenAPI document.

| Endpoint          | Success               | Failure                                               |
| ----------------- | --------------------- | ----------------------------------------------------- |
| GET /health       | 200, status: ok       | Process/network failure means no response             |
| GET /ready        | 200, status: ok       | 503 if migrated/seeded database or bucket unavailable |
| GET /openapi.json | 200, OpenAPI document | Safe error envelope                                   |

Unknown application routes return 404 with statusCode, message and requestId.
Request IDs are generated by the server; caller-provided values are not trusted.
Responses are non-cacheable. CORS allows the configured web origin only.
Requests are limited to 120 per IP per minute in the single local process.
There are no write endpoints or body parsers in Phase 0. Domain DTOs, pagination,
CSRF and role-based authorization become mandatory when their endpoints exist.

OpenAPI is JSON-only to avoid loading external Swagger UI assets or relaxing CSP.
